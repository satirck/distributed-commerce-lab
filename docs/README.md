# Distributed Commerce Lab

Distributed Commerce Lab is a long-term engineering pet project focused on designing and implementing distributed systems using modern backend architecture and infrastructure practices.

The project is intentionally developed as if it were a production system rather than a tutorial application.

## Goals

- Learn distributed systems through implementation.
- Practice Domain-Driven Design.
- Build production-like engineering processes.
- Explore modern infrastructure and cloud-native technologies.
- Document architectural decisions as the system evolves.
